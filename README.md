# Web приложение для бронирования билетов в кино/музей/театр/выставку и т.д.

**Приложение создано в учебных целях с целью изучить:**
    - `Микросервисную архитектуру`
    - `DDD`
    - `Брокеры сообщений`
  

> [!WARNING]  
> Весь фронтенд НАВАЙБКОЖЕН. Создан исключительно чтобы потешить своё эго


## Сервисы

- KrakenD (Gateway)
- KeyCloack (Авторизация и управление ролями)
- Каталог и Бронирование

## Технологии

### Сервис бронирования

| Технология | Назначение |
| --- | --- |
| Python 3.13 | Язык программирования |
| FastAPI, Uvicorn | HTTP API и ASGI-сервер |
| SQLAlchemy, asyncpg | Работа с PostgreSQL |
| Pydantic Settings | Настройки приложения |
| Dishka | Внедрение зависимостей |
| Alembic | Миграции базы данных |
| pytest, HTTPX | Тестирование |
| FastStream | Зависимость для брокеров сообщений; брокер пока не подключён |

### Фронтенд

| Технология | Назначение |
| --- | --- |
| Vue 3 | Пользовательский интерфейс |
| TypeScript | Типизация клиентского кода |
| PrimeVue | Библиотека UI-компонентов |
| Vite | Сборка и запуск фронтенда |

### Инфраструктура

| Технология | Назначение |
| --- | --- |
| KrakenD | API Gateway: маршрутизация, CORS и проверка JWT-токенов и ролей |
| Keycloak, OpenID Connect | Аутентификация, управление ролями и учётными записями |
| PostgreSQL 17 | Хранение данных Keycloak и сервиса бронирования |
| Nginx | Прокси Keycloak и ограничение доступа к разделам кабинета |
| Docker Compose | Сборка и совместный запуск сервисов |

## Запуск

```bash
cp .env.example .env

make up
```

## Тестирование

```bash
make test-booking
```

## Ресурсы

- Фронтенд: http://127.0.0.1:5173/
- Keycloak (через прокси): http://127.0.0.1:8081/
- Бэкенд Бронирования: http://127.0.0.1:8001/docs/

После входа доступны профиль с данными учётной записи Keycloak и админка управления категориями для ролей `admin` и `seller`.
В кабинете учётной записи доступны личная информация и смена пароля; остальные разделы перенаправляются обратно в профиль.
