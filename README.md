# Web приложение для юронирования билетов в кино/музей/театр/выставку и т.д.

**Приложение создано в учебных целях с целью изучить:**
    - `Микросервисную архитектуру`
    - `DDD`
    - `Go`
    - `TypeScript` + `Vue`
  
## Сервисы

- KrakenD
- KeyCloack
- Каталог
- Бронирование
- Оплата и заказы
- Фронтенд приложение

## Запуск

```bash
docker compose up --build -d
```
