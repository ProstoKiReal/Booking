# Каталог мероприятий и Бронирование

## Бизнес требования

- Просмотр каталога мероприятий
- Просмотр конкретного мероприятия
- Запись на мероприятие
- Отмена записи на мероприятия
- Добавление, удаленние, редактирования мероприятия через админку

## Модели

Мероприятие:
(Посмотреть, создать, удалить, посмотреть)
Здесь нет не какой специфичной логики, только CRUD.

- Имя
- Описание
- Тип
- Количество мест
  - Ограничено числом
  - Не ограниченно числом

Бронь:
(Забронировать, отменить бронь, просмотр статуса конкретной брони, посмотреть все брони) 
Здесь есть специфичная логика только на создание и отмену брони

- Пользователь
- Статус: Активна/Отменена

## Технические требования

- Два человека не могут зарегестрироваться на одно место
- Нельзя зарегестрировать больше человек, чем есть мест
- Разграничение прав досупа на доступ к админкам
- Кешируем GET запрос мероприятия

## Расширение в будущем

- Оплата платных мероприятий
- Есть чёткие места (как в кино, театре)
- Возможность задать разную цена у разных мест или фиксированая у всех
- Различные правила отмены брони
